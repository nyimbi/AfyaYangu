    How to map

    Either

    • add a node in the middle of the facility and tag it with the tags below or
    • draw a way around the facility's building and tag it with building=* and the tags below. (It may be necessary to create a multipolygon for complex buildings.)

    Tagging

    Key Value Description Photo

    Main tag

    healthcare blood_donation A facility where you can donate blood, plasma and/or platelets, and possibly have stem cell samples taken

    Information on the facility

    operator * The name of the organization that organises the donation, e.g. Red Cross
    ref * The reference code of the facility, if it has one
    phone * The phone number of the facility
    email * The email address of the facility
    website * The website of the facility
    opening_hours * (Attention: has a specific syntax) The facility's opening hours

    Which components of your blood can be donated

    If some of these are given, others are implied to be unknown. Explicitly add tags with value no if you know the situation.
    blood:whole yes/no Whether or not you can donate whole blood here
    blood:plasma yes/no Whether or not you can donate plasma here. This is done with a plasmapheresis device.
    blood:platelets yes/no Whether or not you can donate platelets here. This is done with a plateletpheresis device.
    blood:stemcells yes/no Whether you can have blood samples taken to determine the tissue type of your stem cells. An appointment might be required.

    Compensation for donation

    donation:compensation no You get no compensation for your donation.
    donation:compensation yes You get a compensation for donating (use the subtags below if you know the type of compensation).
    If yes, tag the type of compensation as well if you know it
    If one or some of these are given, others are implied to be no.[1]
    donation:compensation:payment yes You get paid for each donation, either at the time of donation or after a certain amount of donations.
    donation:compensation:vouchers yes You get one or more vouchers for every donation. Those can be either vouchers for fun rewards at the donation centre itself, or coupons for local businesses.
    donation:compensation:gift yes You can choose a small gift after your donation. In Japan this is called "献血粗品". You do not have to collect vouchers to get these gifts. You may use this tag in combination with donation:compensation:vouchers=yes, this either means that you can choose between vouchers and a small gift, or that you can have both.     JOSM preset

    Blood donation is included in the JOSM preset "Healthcare". To add it, open the JOSM preferences, go to the 3rd tab on the left (the map with the grid on top) and then the 3rd tab on top (Tagging Presets). Select the preset from the Available presets list and click the arrow to the right of the list. Click the OK button at the bottom of the window and accept to restart JOSM.
